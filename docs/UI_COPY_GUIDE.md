# GoldLens UI 文案与界面规范

**目的：** 把“品牌文案”收敛为“软件界面文案”。界面首先要把事情说清楚，其次才是气质。

## 1. 问题清单

之前的 UI 文案存在四类问题：

| 问题 | 例子 | 为什么不像正常软件 |
|---|---|---|
| 隐喻/叙事化 | “这条金路不通”“这一笔没算成”“把一张金店小票拆开” | 用户需要知道发生了什么、下一步做什么，而不是读比喻 |
| 非动作按钮 | “账单已实时更新”做成主按钮 | 按钮应触发动作；状态应显示为状态，不应伪装成 CTA |
| 术语不统一 | Dealer / 门店 / 商家 / 金店混用 | 同一对象应使用同一术语 |
| 过度营销 | “找到敢把回购价写清楚的店”“先懂，再买” | 像广告，不像工具；降低可信度 |

## 2. 规范

### 页面标题

- 使用名词短语：`黄金购买成本计算器`、`市场对比`、`持仓估值`、`价格提醒`、`经销商报价管理`、`运营概览`。
- 不用口号、不用感叹号、不用“今天负责”这类拟人化表达。

### 按钮

- 动词 + 对象：`开始计算`、`提交询价`、`添加持仓`、`创建提醒`、`登录`。
- 不使用状态句作为按钮：`计算已更新` 改为状态标签，不再可点击。
- 一个区域只保留一个主按钮。

### 错误与空状态

- 错误：说明发生了什么 + 用户能做什么。
  - `页面加载失败` / `发生临时错误。你的数据不会丢失，请重试或返回首页。`
  - `页面不存在` / `你访问的页面可能已被移除，或链接有误。请返回首页。`
- 空状态：一句解释 + 一个下一步。
  - `暂无报价。提交询价后，经销商报价会显示在这里。`

### 术语

| 统一使用 | 不再使用 |
|---|---|
| 经销商 | Dealer、门店、商家、金店（混用） |
| 到手价 | 落地价、最终价（混用） |
| 回购价 | 回收价、买回价（混用） |
| 工费 | 手工费、加工费（混用） |
| 纯度 | 成色（在需要精确时） |

### 大小写与标点

- 中文使用全角标点；英文使用 sentence case，不整句大写。
- 标签可用全大写小号字（如 `MARKET`），但句子不用。
- 数字带单位；金额带币种；时间带时区/相对时间。

### 多语言

- 四语言 key tree 必须一致；不允许中文 fallback 出现在 en/th/ar 页面。
- RTL 使用 `dir="rtl"` 与逻辑方向；价格、数字、range 保持 LTR。
- 语言切换放在全局顶部，不放在某个业务表单里。

## 3. 本轮 before / after

| 位置 | Before | After |
|---|---|---|
| 首页主标题 | 买金之前，先看清真实成本。 | 黄金购买成本 / 计算与对比 |
| 首页 CTA | 算一笔真实成本 | 开始计算 |
| 首页模块 | 一块金，到底值多少？ | 快速计算 |
| 计算器标题 | 把一张金店小票拆开。 | 黄金购买成本计算器 |
| 计算器按钮 | 账单已实时更新（可点击） | 计算已更新（状态标签） |
| 对比页 | 同一克，不同世界。 | 市场对比 |
| 询价页 | 拿到可比较的报价。 | 获取报价 |
| 持仓页 | 你的金，今天值多少？ | 持仓估值 |
| 提醒页 | 不用一直刷价格。 | 价格提醒 |
| 经销商页 | 找到敢把回购价写清楚的店。 | 已验证经销商 |
| 知识库 | 先懂，再买。 | 黄金购买指南 |
