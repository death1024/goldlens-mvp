# GoldLens 金价透视 · MVP

> 买金之前，先看清真实成本。

GoldLens 是一个面向消费者黄金购买决策的 Web MVP：把国际金价、泰国 GTA 本地参考价、工费、税费、回购折价和回本点，放进同一张可交互的账单。

**当前版本：0.1 · 2026-10-23**

---

## 快速启动

要求：Node.js 24+，无需安装任何依赖。

```bash
cd mvp
node server.mjs
# 打开 http://127.0.0.1:5188
```

或：

```bash
cd mvp
npm start
```

健康检查：`GET /health`  
市场数据：`GET /api/market`

---

## 已实现功能

- **实时金价**：XAU/USD 现货 + COMEX 主力 1 年日线。
- **泰国本地参考价**：GTA 96.5% 金条/金饰的卖出与回购价。
- **四市场换算**：泰国（THB / 96.5%）、阿联酋（AED / 22K）、印度（INR / 22K）、美国（USD / 24K）。
- **四单位互换**：baht（15.244g）、克、tola（11.6638g）、盎司。
- **真实成本拆解**：金料、工费/溢价、税费、到手价、市场溢价。
- **回购与回本点**：即时回购、一买一卖隐形成本、金价需上涨多少才回本。
- **价格位置**：30D / 90D / 1Y 区间、52 周高/低、当前 vs 均价。
- **持仓**：本地保存，按即时回购价估值，显示浮动盈亏。
- **价格提醒**：浏览器内保存，页面打开时检查；支持系统通知。
- **PWA**：manifest、Service Worker、离线 shell、安装按钮。
- **静态 Demo**：没有 Node 后端时自动回退到 `public/data/market.json` 快照。
- **移动端优先**：390px 无横向溢出，响应式布局。

## 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 国际现货金价 | [gold-api.com](https://gold-api.com/) | XAU/USD，约 10 秒更新 |
| 汇率 | [open.er-api.com](https://open.er-api.com/) | USD/THB、AED、INR、CNY 等每日中间价 |
| 历史走势 | [Yahoo Finance GC=F](https://finance.yahoo.com/quote/GC=F/) | COMEX 黄金主力连续合约日线 |

任一来源失败时，服务端返回最近快照，并在 `degraded` 字段中标注；前端对应数据源显示“快照”。不会假装实时。

## 计算口径

```
金料价值 = 金价(USD/oz) ÷ 31.1034768 × 汇率 × 克重 × 纯度
到手价   = 金料价值 + 工费/溢价 + 税费
即时回购 = 本地回购价 × 重量（或 金料价值 × (1 − 回购折价)）
回本涨幅 = 到手价 ÷ 即时回购 − 1
```

泰国 96.5% 金饰使用 GTA 金饰卖出价作为“到手价”锚，金条卖出价作为“金料”锚，差额即金饰溢价；回购使用 GTA 金饰回购价。阿联酋、印度、美国为国际金料价 + 可调工费 + 可调税费的估算，**不代表任何门店报价**。

## 边界

- 不交易、不托管、不代购、不提供涨跌预测。
- 不是行情终端，也不是投资建议。
- 阿联酋/印度/美国为估算；泰国以 GTA 公告为参考，门店实际价格可能不同。
- 持仓/提醒仅存在浏览器，换设备会丢。
- 公开接口无商业 SLA；生产化需要数据授权、缓存与监控。
